# CodeSync

> Real-time collaborative coding workspace with built-in AI assistance.

CodeSync is a collaborative coding platform designed for developers to write and work on code together in a shared workspace.

It combines synchronous code editing with AI-powered assistance, making it possible to collaborate on code while getting help from an integrated AI assistant.

---

## ✨ Features

- 🔄 **Real-time Collaborative Coding**
  - Write and edit code synchronously in a shared workspace.
  - Multiple users can work on the same file together.

- 🤖 **AI Coding Assistant**
  - Built-in AI chat for coding-related questions and assistance.

- ⚡ **AI Code Completion**
  - AI-powered suggestions while writing code.

- 💻 **Interactive Code Workspace**
  - Browser-based coding environment designed around collaborative development.

- 🎯 **Developer-focused Experience**
  - Combines collaborative coding and AI-assisted development in a single workspace.

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js and npm installed on your machine.

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/keshavvsonii01/CodeSync.git
   cd CodeSync
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🧠 Why CodeSync?

Developers often switch between a code editor, collaboration tools, documentation, and AI assistants while working on a project.

CodeSync explores the idea of bringing these workflows together into a single collaborative development environment:

```text
Collaborate → Write → Ask → Complete
```

The goal is to make collaborative and AI-assisted coding feel like one connected workflow rather than a collection of separate tools.
